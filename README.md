# Rivets of the Dawn Machine (working title)

A game by Toruxas, based on zines by ANTILOVER / DAYWORTH.

This repository only holds test builds of the game for Windows. It does not contain the game's source.

## Download
1. Open [Releases](../../releases/latest) and download `Rivets-x.y.z-windows.zip`.
2. Unzip it anywhere you like (for example Documents), not into Program Files.
3. Double-click `Rivets.exe`. Windows may say "Windows protected your PC": click "More info", then "Run anyway" (the game isn't code-signed yet).

## Updates
Main menu > Check for Updates. When a newer version is out, "Download and install" downloads it, checks it against the published `.sha256` file, replaces the game's files and starts again. Your settings are kept in `%APPDATA%\Godot\app_userdata\Rivets of the Dawn Machine` and are never touched by an update.

## If something goes wrong
Run `Rivets.console.exe` instead: it opens a window with the game's messages. Send a screenshot of any error text.
